# 🩺 生理學期中考 歷屆試題單元互動測驗系統

> 專為醫學生打造的生理學期中考複習系統。打破歷屆年份限制，將郭鐘金、李宗玄、張哲逢、余佳慧、蔡佳醍、吳美玲等老師的試題進行地毯式分類與審查，配備正統臨床心電圖（EKG）與循環生理圖譜，支援即時答題解析、錯題循環重做與同學交流留言板。

---

## 🌟 核心特色

1. **單元化聚焦複習**：依授課教授單元分類（細胞電生理、心臟幫浦、血液動力學、血液免疫、臨床心電圖），讀完一個單元即可一鼓作氣刷完該單元所有考古題。
2. **70 張高解析度正統醫學圖譜**：
   - 蔡佳醍老師 49 張完整臨床十二導極心電圖（房室阻滯、PSVT、心房撲動/顫動、心室頻脈、心肌梗塞等）。
   - 張哲逢老師動脈壓波形、靜脈回流曲線、延腦感壓反射負回饋流程圖、MAP 決定因子架構圖。
   - 吳美玲老師六軸參考系統、心電軸計算、J 點與心肌損傷向量（Injury vector）圖譜。
3. **燈箱式高清放大檢視**：所有附圖題目均支援「點擊放大查看高清圖譜」，支援無級縮放與拖曳，細緻波形纖毫畢現。
4. **極簡純白醫療設計風格**：比照專業醫學測驗系統，排版清爽專注、不傷眼。
5. **錯題循環閉環系統**：答錯題目自動納入複習池，提供「專攻本輪錯題」機制，直至 100% 搞懂為止。
6. **使用者即時留言交流區**：可自訂暱稱，與同學們即時交流刷題心得、標註考點陷阱。
